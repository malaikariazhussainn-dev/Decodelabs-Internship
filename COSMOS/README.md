🚀 About The Project

COSMOS is an interactive Solar System explorer developed as an Internship Task at Decode Labs.

The project transforms a traditional static web page into an interactive experience where users can explore different worlds, view dynamically changing information, discover space missions, compare worlds, save their discoveries, and switch between Day and Night modes.

The project was built with a strong focus on JavaScript interaction, DOM manipulation, responsive design, and an immersive space-themed user interface.


---

✨ Features

🌍 Interactive World Explorer

Select different worlds including Mars, Moon, and Titan

Dynamically update planetary information

Display name, tagline, description, distance, temperature, and moons

Previous / Next navigation

Keyboard navigation using ← and →


🔬 Deep Dive

Explore detailed information about each world, including:

Diameter

Gravity

Day length

Year length

Atmosphere

Surface

Exploration information


🛰️ Mission Archive

View missions related to the selected world

Mission cards with agency, year, status, and description

Open missions for detailed information


⚖️ World Comparison

Compare different worlds using key information such as:

Diameter

Gravity

Day length

Year length

Temperature

Distance

Number of moons


♡ Save to Archive

Save your favourite worlds

Remove saved worlds

Persistent saved state using browser localStorage


☀️ Day / Night Mode

Switch between Day and Night modes

Dynamic theme icon

Header and footer adapt to the selected mode

Theme preference is remembered after refreshing

Responsive toggle for mobile and desktop


🎬 Cinematic Solar System Background

A full-screen Solar System video creates an immersive visual experience while users explore the interface.

💾 Data Persistence

COSMOS uses browser localStorage to remember user preferences.

Currently stored information includes:

cosmosSavedWorlds
cosmosMode

This allows saved worlds and the selected Day / Night mode to remain available after refreshing the page.
